# Протокол юзабіліті-оцінювання (крок 12)

Учасники: щонайменше 3 одногрупники, які **не бачили** застосунку. Режим — демонстраційний
(`PYTHONPATH=. uv run streamlit run tests/demo_app.py`): однакові відповіді для всіх, квота не витрачається.
Не підказуйте. Фіксуйте час (секундоміром) від початку читання задачі до виконаної дії.

| № | Сценарій | Задача для учасника | Критерій виконання |
|---|---|---|---|
| 1 | UC1 | «З'ясуйте, яким має бути початок сцени за правилами команди, і відкрийте джерело» | натиснуто посилання на нотатку |
| 2 | UC2 | «Підготуйте сцену: герой стоїть сам у ліфті, який зупиняється між поверхами» | отримано звіт зі сценою |
| 3 | UC4 | «Збережіть сцену в базу знань» | з'явилося повідомлення «Збережено» |

Після задач — анкета SUS (10 тверджень, 1–5; тексти в МВ, табл. 1.7). Відповіді — в `eval/sus_responses.csv`
(`respondent,q1,...,q10`, приклад формату: `eval/sus_example.csv` — ВИГАДАНІ дані, лише для перевірки скрипта).
Час і спостереження — в `eval/usability_results.csv`. Обчислення: `uv run python -m eval.sus eval/sus_responses.csv`.

Порівняння UC2 «вручну»: засічіть, скільки часу потрібно на ту саму сцену без робочого місця
(ваш власний замір або оцінка учасника) і запишіть у звіт, звідки взято число.

Внесіть щонайменше одне виправлення за спостереженнями й опишіть його у звіті (що спостерігали → що змінили).
