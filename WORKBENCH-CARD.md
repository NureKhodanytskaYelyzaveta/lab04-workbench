## 2. Призначення
- Етап ЖЦ ПЗ: 3 Проєктування
- Користувач: гейм-дизайнер (проєктує сцени гри на Unity)
- Задачі, які пришвидшує (3): (1) знайти правила й обмеження проєкту в базі знань; (2) отримати перевірену чернетку сцени — біти, крива страху, звук, візуальні ефекти, репліки внутрішнього голосу; (3) передати сцену розробнику у форматах для Unity
- Артефакт етапу: `scene.json` (крива страху 0..1, біти, звук, ефекти — для FearLevelController і скриптів сцени), `scene.yarn` (вузол Yarn Spinner з репліками), `scene.md` (проєктна документація); розробник на етапі конструювання імпортує JSON і .yarn у проєкт, а .md використовує як специфікацію
- Межі: не пише C#-код, не створює арт, аудіо й шейдери, не запускає Unity; не гарантує «страшність» (лише формальну узгодженість); не змінює наявні нотатки бази знань (пише тільки нові в Inbox/)

## 3. Склад
- База знань (ЛР 2): сховище Obsidian <назва>, <N> нотаток; ембединги gemini-embedding-001 (768); Chroma
- Мультиагентна система (ЛР 3): агенти scene_designer, audio_designer, visual_designer, director; детерміновані вузли intake, retrieve_context, scene_check, link_check, gate, publish; граф — docs/architecture.md
- Інтерфейс: Streamlit <версія>; вкладки: Питання до бази знань, Команда агентів, Історія і метрики
- Журнал: SQLite (workbench.db); метрики: запусків, виклики LLM, токени, час, частка позитивних оцінок, частка збережених результатів

## 4. Запуск
- uv run streamlit run streamlit_app.py
- Демонстраційний режим: PYTHONPATH=. uv run streamlit run tests/demo_app.py
- Змінні оточення: GEMINI_API_KEY, OBSIDIAN_VAULT, CHROMA_PATH (значення не наводити)

## 6. Безпека і людина в циклі
- Що потребує підтвердження людини: запис сцени в базу знань — лише після прапорця «Я перевірив…» і введеного імені рецензента (сервіс додатково вимагає confirmed=True); ім'я фіксується в `approved_by`
- Ліміти: 10 запусків команди і 30 питань за сесію; до 12 викликів моделі на запуск (3 чернетки × 4 агенти); запит 15–2000 символів; запис лише в Inbox/ без перезапису; сервер слухає лише localhost; статистика Streamlit вимкнена; ключ лише в .env

## 7. Відомі обмеження та ризики
- Якість сцен оцінює людина; детерміновані перевірки не вимірюють «страшність».
- Чат і команда залежать від квоти безкоштовного рівня Gemini API (429/503); запуск, що не вдався, не потрапляє в журнал.
- Якщо в базі знань немає релевантних нотаток, команда працює без контексту (NOT_FOUND).
- Нотатки бази знань потрапляють у промпт дизайнера сцени: захист — теги `<fragment>`, агенти без інструментів запису.
- Збережену нотатку потрібно переіндексувати вручну (`uv run python -m kb.indexer`).
